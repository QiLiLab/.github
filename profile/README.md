# Qi & Sky Lab

**Multimedia Security · AI Security · Cybersecurity**  
多媒体安全 · 人工智能安全 · 网络安全

We study the security and trustworthiness of digital media and AI systems.
Our work connects image watermarking, information hiding, multimedia
forensics, machine learning privacy, and cybersecurity.

我们研究数字媒体与人工智能系统的安全与可信问题，关注图像水印、
信息隐藏、多媒体取证、机器学习隐私及网络安全。

## Research directions

- **Digital media security:** invisible image watermarks and attacks,
  steganography, image encryption, and multimedia forensics.
- **AI security and privacy:** machine learning attacks, privacy auditing,
  federated learning, and machine unlearning.
- **Cybersecurity:** network traffic analysis, vulnerability research,
  and the security of AI-assisted software systems.
